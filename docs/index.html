Install in Kodi

  1. Add this page's address in Settings → File manager → Add source. Name it Arr Bridge.
  2. Open Add-ons → Install from zip file → Arr Bridge and select the repository ZIP above. Enable Unknown sources if prompted.
  3. Choose Install from repository → Arr Bridge Repository → Program add-ons → Arr Bridge → Install.
  4. Enable Auto-update on Arr Bridge's information page. Kodi's global update setting must also allow automatic installation.

If Arr Bridge was installed manually, select this repository in Versions (or Update, depending on the skin), even if the version is already installed. Keep your existing installation and settings.

Alternatively, download the repository ZIP in a browser and select the local file in Kodi. Future updates come from the repository's direct GitHub feed; the page is only needed for installation.
